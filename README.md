# Vijay Dental — Vercel sample

1. Extract this ZIP.
2. Upload the contents of Vijay-Dental-Vercel to a new GitHub repository.
3. In Vercel, import that repository.
4. Framework Preset: Other. Root Directory: repository root. No build command. Output Directory: public (also specified in vercel.json).
5. Deploy and share the resulting URL.

No npm install, backend, API keys or environment variables are required. All seven image assets are included. Google Fonts requires an internet connection; system fonts provide fallbacks.

Edit public/index.html to change text and contact links. This static sample has 14 actual pages: home, treatments, about, doctors, gallery, contact, appointment, privacy, and six individual treatment pages. Gallery photographs open in dialogs. Shared CSS and JavaScript live in public/assets. Serve the public directory over HTTP; do not open nested HTML files with file://.

Personal contact numbers and call/WhatsApp links have been removed.

The appointment form is a local demonstration only; it does not send or book requests.

This sample is intentionally noindex. Before a real clinic launch, replace sample profiles/photos/contact details with verified clinic information and remove the robots meta tag and X-Robots-Tag header. Separate treatment URLs are included; accurate clinic details and real content are still needed for production SEO.
